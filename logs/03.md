# 03 - Staged deployments

## 実施内容

- `.github/workflows/github-actions-demo.yml` の manual trigger に `environment` input を追加
- `Build` 後に `Test` と `Load-Test` が動作する job を追加
- `Test` と `Load-Test` 完了後、Production が選択された場合だけ `Production` job が動作する設定を追加
- Production environment に deployment URL `https://writeabout.net` を設定
- Production job に5段階の deployment simulation を追加

## GitHub environment

- `Test` / `Load-Test` を GitHub CLI で作成
- `Production` を作成し、required reviewer に `tsubakimoto`（ID: `1592808`）を設定
- `Production` の deployment branch policy を custom branch policy にし、`main` branch だけを許可
- GitHub API の再確認で3 environments、required reviewer、`main` branch policy を確認
