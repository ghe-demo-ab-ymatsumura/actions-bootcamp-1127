# 04 - Reusable workflows

## 実施内容

- `.github/workflows/reusable.yml` を作成
- `workflow_call` に required な `who-to-greet` string input（default: `World`）を追加
- reusable job で挨拶し、`$(date)` を step output `time` と workflow output `current-time` に連携
- `.github/workflows/reuse.yml` を作成
- manual trigger から `@tsubakimoto` を input に local reusable workflow を呼び出し
- 呼び出し元の `use-output` job で `needs.call-workflow.outputs.current-time` を出力
