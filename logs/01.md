# 01 - My first workflow

## 実施内容

- `.github/workflows/github-actions-demo.yml` を作成
- `main` への push（`.github/**` は除外）、`main` 向け pull request、毎週日曜 06:15 UTC、手動実行を設定
- `ubuntu-latest` 上の `Build` job を追加
- trigger、branch、repository の情報を出力
- `actions/checkout@v4` で repository を checkout
- `tree` で repository 内のファイル一覧を出力
